# v7: обучение с подкреплением, проактивность, связи вопрос→ответ

## Что было не так (найдено в v6)
- Автообучение на непроверенных ответах LM оставалось, хотя v5c обещал его отключить.
- train_words не создавал связи между вопросом и ответом, стоящими дальше окна TRAIN_WINDOW.
  Поэтому мысль по только что выученному ответу не находилась (support = 0).
- При заполненной сети (702 из 700 нейронов) новые слова из /teach молча отбрасывались.
- Кандидаты ответа содержали повторы («обсуждают share обсуждают share»).
- На «привет» при пустом ответе LM выводилось «пока не знаю этого».

## Что сделано
- rl_policy.py (новый): Thompson sampling по стратегиям (режим подсказки: вся сеть / группа /
  без подсказки; переписывание вкл/выкл). Награда: /good = 1, /bad и /teach = 0. policy.json.
- reasoning.py: стратегия выбирается бандитом при работающей LM; приветствие получает ответ;
  unknown_reply() — проактивный ответ (называет непонятные слова, просит /teach);
  граф не обучается в final(), только по награде.
- brain_chat.py:
  - автообучение убрано; /good дистиллирует логиты LM (distill_from_lm) с весом оценки;
  - /good и /teach связывают вопрос и ответ через Brain.associate;
  - /bad даёт награду 0 и предлагает /teach;
  - при низкой уверенности выводится подсказка оценить ответ;
  - новая команда /policy: оценки стратегий;
  - /teach сообщает, если слова не поместились, и предлагает /neurons 1000.
- mind.py: повторы слов в кандидатах убираются.
- episodes.py, lm_backend.py, rl_policy.py: пути читаются во время вызова (тесты их подменяют).
- Тесты: test_rl_proactive.py (новый, 6 проверок); _isolate.py — тесты не трогают файлы проекта.
  Заглушки test_lm.py и test_commands_v4.py дополнены backend_used, как у настоящего класса.

## Проверки
Все тесты проходят в изолированной копии: test_rl_proactive, test_pipeline_fakelm,
test_commands_v4, test_e2e_headless, test_lm, test_sse.
Не проверено: GUI pygame на вашей машине и реальная GGUF/LM Studio модель.

## Важно
- Первые ответы стратегии выбираются почти случайно (исследование). Оценки /good и /bad
  постепенно выделяют лучшую стратегию; смотрите /policy.
- Ваша сеть на 702 нейронах: чтобы новые слова запоминались, поднимите лимит: /neurons 1000.
- Связи вопрос→ответ создаются только явным обучением (/teach, /good), не автоматически.
