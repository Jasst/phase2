# v19: логичный порядок мысли и адаптивность

## Что означают ползунки (уточнено в GUIDE.md)
- Частота мыслей — интервал фонового мышления: `think_sec` (2.0 с → 0.15 с).
- Длина ответа — верхний предел слов (`target`), теперь цепочка может закончиться раньше.
- Зазор между словами — пауза речи: `gap_sec` (0.05 → 3.0 с).

## Что изменено
- `Mind.chain_from` — генеративная цепочка: старт с затравки, дальше самое сильное
  продолжение по биграммам из текста (порядок подтверждён текстом), с поправкой на
  связи графа и контекст вопроса. Служебные слова разрешены (они держат фразу).
  Цепочка обрывается, когда продолжение слабеет (`CHAIN_STEP_MIN`).
- `Mind.order_path` — порядок выбранных кандидатов по связям графа, обрыв на слабом шаге.
- `Mind._n_candidates` — адаптивный поиск: при слабой опоре в последних ответах
  (`support_hist` < 0.3) сеть пробует больше вариантов (`CANDIDATES_WEAK`).
- В `Mind.answer` цепочка по тексту добавляется как вариант с бонусом `CHAIN_BONUS`.

## Честный результат
- Цепочка по тексту даёт связные фразы из корпуса («а слова которые часто встречаются
  рядом притягиваются»), это подтверждено тестом и прогоном.
- Сквозные мысли в окне пока короткие и не всегда осмысленные. Причина в данных:
  корпус проекта — 145 строк, 1022 биграммы. Логика выбора и порядка работает, но
  без большего текста связная мысль не получится. Загружайте тексты через
  перетаскивание `.txt` в окно.
