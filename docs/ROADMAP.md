# Что реализовано из предложений: статус и проверка

Статусы: **сделано** — работает и проверено тестом или в браузере; **частично** — механизм
есть, но качество или полнота ограничены; **не сделано** — пока только идея.

## Предложенное мной

| Пункт | Статус | Что сделано | Как проверить |
|---|---|---|---|
| Непрерывность мысли между ходами | сделано | Мысль (`net.thought`) переживает ходы, смешивается с новым вопросом (фокус) и сохраняется на диск | `test_thought_persists_between_turns`; страница «Сеть»: карточка «Мысль (фокус)» |
| Внутренний расчёт до ответа | сделано | `settle_steps` шагов импульса до ответа. Говорим из фокуса: без расчёта первое слово вопроса теряется | `_settle` в `net.py`; тест `test_respond_reproduces_taught_answer` |
| Самопредсказание | частично | Сеть предсказывает следующий шаг цепи и сравнивает с реальным. Ошибка видна на странице и в трассе. **В обучение пока не идёт** | карточка «Ошибка самопредсказания»; `test_self_prediction_error_and_confidence_are_reported` |
| Уверенность и «не знаю» | частично | Уверенность — масса устаканившейся мысли. Ниже порога сеть честно говорит, что не уверена. Порог (0.02) не калиброван на данных | `test_unknown_question_is_reported_as_unknown_not_guessed` |
| Эпизодическая память | частично | Журнал уроков с источником (`episodes.json`) и выводом на странице. **Вспоминания по теме пока нет** | блок «Журнал уроков» |
| Проверочный набор и метрика | сделано | Набор растёт сам: каждый «Хороший ответ» добавляет вопрос с его словами. «Проверить припоминание» считает долю слов, которые сеть вспоминает | `test_good_answer_adds_eval_item_and_eval_runs` |
| Рост без ограничений | частично | Число ансамблей растёт вдвое при нехватке (`Cortex.grow`). Шаг цепи считается только по активным ансамблям. Но матрица связей плотная: память ~ число_ансамблей² × 4 байта (≈64 МБ при 4096). Дальше нужна разреженная матрица | `test_capacity_grows_without_fixed_limit` |

## Предложенное вами

| Пункт | Статус | Что сделано |
|---|---|---|
| Переключатель «LLM / моя модель» в чате | сделано | Панель над полем ввода. В режиме «Моя модель» LLM не вызывается, отвечает сеть |
| Кнопка «Обучить» | сделано | Даёт урок с текущей парой вопрос→ответ |
| Кнопка «Переучить» | сделано | Вводите правильный ответ. Правильный закрепляется весом 2, неверный ослабляется весом −2. Обычно достаточно 2–3 исправлений |
| Кнопка «Хороший ответ» | сделано | Закрепляет пару и добавляет её в проверочный набор |
| Автообучение из ответов LLM (переключатель) | сделано | Галочка «учить из ответов LLM» |
| Логичная цепочка мыслей | частично | Мысль + фокус + расчёт + цепь. Связность ответов ограничена размером сети и корпусом: сейчас 154 слова |
| Фокус на ответе, без шума | частично | Фокус на вопросе, top-k в каждом шаге, затухание пройденных ансамблей. Полностью шум не устранён: ответы остаются ассоциативными |
| Настройки | сделано | Окно «Настройки» возвращено из исходного интерфейса. Раздел «Сеть»: режим по умолчанию, автообучение и шесть параметров (температура, порог «не уверена», шаги расчёта, фокус, повторы, вес исправления) с проверкой границ |
| Проверка модели в чате | сделано | Панель показывает вопрос, ответ и источник последнего хода |
| Обучение через интерфейс | сделано | Все уроки — с страницы «Сеть» и из чата, сохраняются на диск |

## Что я улучшил в предложенном

- **«Сознание»** переведено в измеряемые свойства: непрерывная мысль, самопредсказание, уверенность, припоминание. Сознание как таковое этой архитектурой не доказывается и не достигается простым повторением уроков.
- **«Переучить»** работает через две стороны: правильный ответ усиливается, неверный ослабляется. Раньше ослабления не было, и старый ответ всплывал снова.
- **Проверка** не требует ручного набора тестов: проверочный набор строится из ответов, которые вы подтвердили.
- **Исправлены ошибки** найденные при проверке: счётчик уроков считал повторы, сброс затирал сохранение, кнопка установки не работала, пункты меню вели в несуществующие страницы.

## Что не сделано

- Самопредсказание не используется для обучения. Сейчас это только метрика.
- Эпизодической памяти нет: журнал записывает, но не извлекает.
- Связные ответы на общие вопросы. Сеть в 154 слова отвечает ассоциациями.
- Калибровка уверенности и порога «не знаю».
- Разреженная матрица связей для очень больших сетей.
