# v11: надёжность загрузки и чистка кода

## Надёжность
- `/load` больше не роняет чат на повреждённом файле. При ошибке текущая сеть
  остаётся на месте, пользователь видит причину.
- `load_brain` проверяет структуру файла: чужой JSON и файл без поля `neurons`
  дают понятную ошибку (ValueError), а не KeyError внутри загрузки.
- Защита от будущих форматов: если `version` новее поддерживаемой (сейчас 6),
  загрузка отказывается с сообщением, а не читает файл наугад.
- `load_dict` терпит отсутствующие `links` и `bigram` в старых сохранениях.
- Версия формата вынесена в константу `BRAIN_FORMAT`, `to_dict` берёт её оттуда.

## Производительность
- `Mind._integrate`: активные группы раньше вызывали полный обход словаря слов
  на каждую группу (O(G·W)). Теперь один проход по словам (O(W)).
  Результат идентичен: проверено на 300 шагах со сравнением со старой версией.

## Чистка кода
- `cosine` и `key` были продублированы в `brain_chat.py` и `mind.py`.
  Теперь импортируются из `mind.py`.
- Переменная цикла `key` в `draw_panel` затеняла функцию `key`. Переименована в `font_name`.
- Удалён неиспользуемый импорт `LEARN_MIN`.
- pyflakes для `mind.py` и `brain_chat.py` чист.

## Проверки
- Реальный `brain_state.json` (1084 нейрона, 661 связь) загружается.
- Сохранение и загрузка дают тот же граф.
- Битый JSON, чужой JSON и версия из будущего дают понятные ошибки.

## Не проверено автоматически
- Команда `/load` в живом окне pygame: логика проверена чтением и компиляцией,
  но в GUI не запускалась.
