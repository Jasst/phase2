# v16: производительность, интерфейс сети, перетаскивание файлов

## Почему сеть «забивала процессор»
1. **Лавина возбуждения.** Фоновое мышление возбуждало лавину: за шаг горело около
   600 из 1700 нейронов (треть сети). Исправлено k-WTA: за шаг горит не больше 2%
   нейронов (`FIRE_CAP`), принудительные (ответ, анимация слов) горят всегда.
   Проигравшие сохраняют потенциал. Это и главная причина белой «сетки» на экране.
2. **Отрисовка каждого кадра.** Гало для всех нейронов, кривые Безье для всех связей,
   пересчёт оболочек групп на каждом кадре. Теперь: гало только у горящих,
   кривые только у горячих и выбранных связей, холодные связи — на статичном слое,
   который обновляется раз в ~0.5 с, оболочки групп — раз в 8 кадров, всё за экраном
   не рисуется.

Замеры (headless, сеть из корпуса проекта):
- отрисовка сцены: 48 мс → 8.4 мс на кадр;
- горящих нейронов за шаг фонового мышления: ~600 → ~23 (из ~1700).

## Что добавлено
- **Перетаскивание файла** (`.txt`) в окно: сеть обучается на тексте, в чат
  выводится число строк и слов. Текст, перетащенный из другой программы, вставляется
  в строку ввода.
- **Кнопка «активировать»** в меню нейрона (ПКМ): нейрон сработает на ближайшем шаге,
  а левое полушарие начнёт думать о его слове.
- **Подсказка управления** в правом нижнем углу сетевой области.
- Горячие связи — спокойный голубой цвет, окно подсветки 0.8 с (было 2 с).

## Ограничения (честно)
- Чат ещё не переработан полностью: остаются один столбец сообщений, без выбора и
  копирования по сообщению. Это следующий этап.
- Подписи слов иногда накладываются друг на друга в плотных местах.
- Статичный слой связей отстаёт на ~0.5 с: только что появившаяся связь
  рисуется живым слоем, а её «холодная» версия обновляется с задержкой.
- Ответ пользователя на вопрос фонового интерфейса пока не обучает сеть.
