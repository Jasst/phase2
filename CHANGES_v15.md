# v15: три слоя с разведёнными ролями (cortex.py)

## Что изменено по запросу
1. **Прямой слой (FeedForward)** — только обрабатывает. Активность слов переносится
   вверх по слоям нейронов (вход → ассоциации → интегратор → речь), хабы гасятся,
   доминирующая группа подтягивает своих членов. Связей не пишет.
2. **Рекуррентный слой (Recurrent)** — гоняет активность туда-обратно до стабилизации.
   Единственный слой, который создаёт новые связи: между словами, которые возбуждаются
   вместе и ещё не связаны. Бюджет `NEW_MAX` за проход, вероятность создания
   `1 - exp(-T·s)`, как в `core.learn_sequence`. Служебные слова связей не получают.
3. **Внутренний слой (Internal)** — картина мира: группы слов, их сплочённость, мосты
   между группами. По пробелам задаёт вопросы: часто встречающееся слово почти без
   связей; группа с неясной связностью; две крупные группы без моста. Каждый вопрос
   задаётся один раз. Граф не меняет.
4. **Слияние с приложением** — фоновый проход каждые `CORTEX_EVERY` секунд, только
   когда сеть не отвечает и LLM не занята. Вопросы появляются в чате от «Сеть».
   Команда `/cortex` — состояние слоёв.

## Файлы
- Новые: `cortex.py`, `tests/test_cortex.py`, `patch_cortex.py`, `CHANGES_v15.md`.
- Изменён `brain_chat.py` — 6 точечных замен (`patch_cortex.py`): импорт, константа
  `CORTEX_EVERY`, состояние, фоновый проход, команда `/cortex`, строка справки.

## Контракт слоёв (проверяется тестами)
- Прямой и внутренний слои не меняют `brain.links`.
- Прямой слой не переносит сигнал вниз по слоям нейронов.
- Рекуррентный создаёт связь между совместно активными словами при ненулевом бюджете
  и не создаёт при нулевом.

## Ограничения (честно)
- Служебные слова задаются списком `STOPWORDS` из `mind.py`; список неполный
  (например, «между», «когда» иногда попадают в вопросы).
- Вопросы — шаблоны, не понимание. Ответ пользователя на вопрос сейчас не обучает сеть:
  для обучения используются `/teach` и `/good`.
- Картина мира не сохраняется между запусками (пересчитывается из графа).
