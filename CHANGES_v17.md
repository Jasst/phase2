# v17: понятные подписи мыслей, ответов и статуса

## Что изменено
- Новый модуль `explain.py` (чистый, без pygame): уверенность словами (низкая /
  средняя / высокая), название темы по самому частому слову группы, подпись
  фоновой мысли «Ход мыслей: …», подпись ответа «Сеть · уверенность …», статус сети.
- Мысли: «Мысль · тема «…» · уверенность …: слово → слово». Старые «группа 5, оценка 0.21»
  и «опора» убраны из интерфейса. `Thought.describe()` не менялся (тесты на него остаются).
- Строка статуса справа вверху сетевой области: отвечаю / думаю над ответом / учусь /
  жду вопрос.
- Подписи панели полушарий: «связные слова» и «ассоциации» вместо «анализ» и «блуждание».
- Подсказка панели мыслей: «ассоциации сети, не ответы».
- `/help`: строка «Как читать…».
- `GUIDE.md` — руководство по окну для пользователя.

## Файлы
- Новые: `explain.py`, `patch_explain_v17.py`, `tests/test_explain.py`, `GUIDE.md`, `CHANGES_v17.md`.
- Изменён `brain_chat.py` (патч `patch_explain_v17.py`, 11 замен, поверх v16).

## Проверки
- `tests/test_explain.py`: 9 тестов (пороги уверенности, название темы, формат мысли,
  приоритет статуса, отсутствие служебных терминов в подписи ответа).
- Все остальные тесты проекта проходят. Прежние провалы в `test_nets_integration` и
  `nets/tests` не связаны с этими изменениями.
- Скриншот живого окна: `ui_v17_screenshot.png`.

## Ограничения
- Фоновые мысли остаются случайным блужданием по ассоциациям. Подписи объясняют это,
  но не делают мысли связными текстом.
- Подписи на нейронах и слиянии групп не переписаны полностью.
