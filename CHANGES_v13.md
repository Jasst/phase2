# v13: взаимодействующие сети (пакет nets/) и цепочка мыслей

## Главное
Граф слов (`brain_chat.py`, `mind.py`) теперь дополнен ансамблем из нескольких
сетей. Сети работают цепочкой: выход одной становится входом следующей, пока
мысль не стабилизируется. Цепочка конкурирует с мыслью графа за место мысли
«вся сеть». Обучение идёт по наградам пользователя (`/good`, `/teach`) через
изолированную песочницу, которая коммитит изменения только при росте качества.

## Что добавлено
- `nets/` — новый пакет в корне проекта; все сети и их файлы в одной папке:
  - `core.py` — сеть: узлы-слова, веса, температурные переходы
    `p(j|i) ∝ exp((log(1+w) − HUB·log(1+deg_j)) / T)`, асинхронный проход в
    случайном порядке узлов, дистилляция, мутации, `prune()` (ограничение графа);
  - `chain.py` — цепочка сетей: выход → вход, «общее число» (накопленная сумма
    выходов), обратная связь мысли, стабилизация, динамическое число раундов
    по энтропии, лимит времени;
  - `transfer.py` — матрица перерасчёта `M_AB = Σ_k P_A(k|i)·P_B(j|k)` через общие
    узлы и её дамп в `_matrices/`;
  - `cluster.py` — мутации ансамбля, кластеризация по откликам, (1+λ) эволюция;
  - `sandbox.py` — изолированная адаптация: копия, обучение, отбор, дистилляция,
    проверка на отложенной выборке, коммит при росте качества;
  - `manager.py` — `NetsManager`: открытие, мысль, очередь наград, адаптация,
    сохранение, статус, логи;
  - `build.py`, `store.py`, `demo.py`, `README.md`, `tests/`.
- `reasoning.py` — `Answerer(brain, mind, nets=None)`; `_chain_thought()`;
  метка `CHAIN`; `_where()` для описания мыслей.
- `brain_chat.py`:
  - создаётся `NetsManager.open()`, передаётся во все три `Answerer(...)`;
  - `/good` и `/teach` отправляют пару в `nets_mgr.feedback(...)`;
  - `/save`, автосохранение и выход сохраняют сети;
  - новые команды `/nets` (состояние) и `/chain` (трасса последнего ответа);
  - строка справки о цепочке.
- `_isolate.py` — тесты перенаправляют папки сетей во временную папку.
- `test_nets_integration.py` — 5 тестов интеграции.
- `nets/tests/test_nets.py` (18 тестов) и `nets/tests/test_manager.py` (11 тестов).

## Соответствие запланированному
| Задача | Реализация |
|---|---|
| Сети по слоям и группам | цепочка сетей; кластеры откликов в `cluster.py` |
| Связи создаются с температурой | `learn_sequence`: P(создать)=1−exp(−T·gain) |
| Умное распределение весов | softmax по log(1+w) с гашением хабов |
| Дистилляция знаний | `distill_from`: мягкие цели учителя при T_d |
| Взаимодействующие сети | цепочка с накоплением выходов и обратной связью |
| Изолированная среда адаптации | `Sandbox`: глубокая копия, коммит по порогу |
| Мутации в кластеры | `mutate_ensemble`, `cluster_nets`, `evolve` |
| Запись слоёв информации | трасса по раундам, `chain_history.jsonl`, `feedback.jsonl` |
| Случайный порядок нейронов | асинхронный проход, порядок задаётся `seed` |
| Безграничное развитие | опыт растёт без предела; активный граф ограничен `prune` |
| Матрица перерасчёта | `transfer_matrix` + дамп в `_matrices/` |
| Динамическое время | число раундов по энтропии, `time_budget` |
| Все сети в одной папке | `nets/` |

## Проверки
- Существующие тесты (`test_*.py`): все прошли без изменения ожиданий.
- `nets/tests`: 29 тестов, `test_nets_integration.py`: 5 тестов — все прошли.
- Ошибка, найденная тестом и исправленная: `load_ensemble` читал служебный
  `pending.json` как сеть. Теперь служебные файлы пропускаются.

## Ограничения (честно)
- Это не нейросеть с градиентным спуском. Обучение — Хебб по совместной встрече,
  мутации и дистилляция по распределениям.
- Знания цепочки ограничены текстами проекта и подтверждёнными парами. Слово вне
  текстов даёт пустую мысль, и сеть ничего не выдумывает.
- Оценка качества — совпадение слов. Смысл оценивает пользователь через /good.
- `brain_state.json` и `episodes.json` в новой версии не менялись по формату.
