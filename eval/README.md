# Измерение гейтов брифа

Здесь только инструменты. Результаты пишутся в `eval/results/` и не заменяют приёмку на ваших данных.

## G2: recall LSH-кандидатов (порог 0.90)

    python eval/eval_g2.py                                       # синтетика, офлайн
    python eval/eval_g2.py --encoder openai --url http://127.0.0.1:8091/v1 --dim 1024

## G3: F1 экстракции фактов (порог 0.80)

1. Соберите набор `eval/gold.jsonl`: 100 реплик, в каждой ожидаемые факты в формате `{"s","r","o"}`.
   Шаблон — `gold_example.jsonl`. Размечайте по тем же правилам, по которым извлекает модель:
   «я» заменяйте на имя из `TRIPLEX_USER_NAME`.
2. Запустите:

       python eval/eval_g3.py --gold eval/gold.jsonl --url http://127.0.0.1:8080/v1 --model <имя модели>

Связывание сущностей (acc ≥ 0.90) не покрыто: для него нужна отдельная разметка идентичности сущностей.
